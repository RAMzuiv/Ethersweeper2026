# Ethersweeper

Design by MRPW, with some work by Claude.ai.

A minesweeper whose neighbourhoods are chess-piece move patterns and whose mines appear as you play.
It is a single self-contained page (`index.html`: the game, its music and its sounds are all inside it), so it works as a static site.

Tap a tile to sweep it. Tap the background to switch between sweep and flag mode.
